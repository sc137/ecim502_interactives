Backups give you a way back

Family photos, letters, financial records, and class projects can be difficult or impossible to replace. A backup is a separate copy you can restore when the original is deleted, damaged, encrypted by malware, or lost with a device.

Hardware failure or loss

A drive can stop working. A phone can disappear. Fire or theft can take both a computer and the drive beside it. A separate, offsite copy keeps one event from taking everything.

Malware and mistakes

Ransomware is malware that can lock files by encrypting them. A backup that malware cannot reach, with a clean earlier version, gives you a recovery option. Backups also help undo accidental deletion.

The 3-2-1 backup rule

3 copies

Your working original plus two backup copies of each important file.

2 storage media types

Use different media or storage technologies, such as a local external drive and a cloud backup service. Two folders on the same drive share a failure point.

1 copy offsite

Keep at least one copy away from your home, such as a cloud backup or a drive stored safely elsewhere.

Example: The original photos on your computer, a versioned backup on an external drive, and another backup in the cloud. Disconnect the external drive after its backup finishes. Check that the same important files are included in both backups.

Make those copies useful

  • Automate frequent backups and check that they finish successfully
  • Keep older versions long enough to discover a problem
  • Keep a backup offline or protected against changes and deletion
  • Test restoring a few files to a separate folder and open them
  • Protect backup accounts with multifactor authentication, and keep recovery codes and encryption keys somewhere safe
Sync is useful, but check its limits. Synchronization keeps files alike across devices. It may also spread deletion or corrupted files. Check version history, recovery limits, and a separate backup rather than assuming sync alone is a complete plan.

Backup Lab: What could you recover?

Choose how much to back up, where to keep it, and what goes wrong. This is a model for learning; it does not access your files or change a device.

Documents folder

Saves files inside Documents. Photos, Desktop files, and files stored elsewhere need their own coverage. Uses less space, but it is easy to miss something important.

Home folder

Saves one user's personal folder, including Documents, Pictures, Desktop, and Downloads in this model. Does not include other users or the operating system and installed apps.

Full machine

For this model, a supported system-image backup includes all users, installed apps, and the operating system. Needs more space and a compatible recovery method. A service advertising “all your files” may still exclude system files.

Model assumptions: The latest backup finished yesterday. All selected files were available locally and included successfully. The malware event began today. Offline and cloud history copies contain a clean version from before infection. Cloud accounts remain accessible. Real backup tools have exclusions, storage limits, and restore requirements.

Recovery result

Try a comparison: Test Documents against hardware failure. Then try Home folder and Full machine. Keep Full machine selected and compare the always-connected drive with the 3-2-1 plan during ransomware. Does a larger backup fix an unsafe location?

Back up a Windows computer

Start with the files you cannot replace. Then decide whether you also need system recovery.

Cloud folders: Windows Backup

  1. Open Start, search for Windows Backup, and open it
  2. Sign in with a personal Microsoft account; work or school accounts do not work in this consumer app
  3. Review the available folders, such as Documents, Desktop, and Pictures, and turn on the ones you need
  4. Run the backup and verify its status and available OneDrive space

This uses OneDrive folder sync and saves selected settings and app information. It is not a complete system image; apps may need to be installed again.

Add a separate local backup

Use File History with an external drive for versions of personal files. Check included folders and test restoring one file. For a full-machine image, select a supported imaging tool and learn its recovery steps before you need them.

Check the gaps: Files outside selected folders, other users, external drives, and cloud-only files may need separate attention. Disconnect your local backup drive when it is not backing up. Keep an offsite copy too.

Back up a Mac

Use Time Machine

Time Machine is Apple's built-in backup tool for personal data, including documents, photos, and apps. It keeps earlier versions so you can recover an older file.

  1. Connect a suitable external backup drive
  2. On macOS Ventura or later, open System Settings → General → Time Machine
  3. Select Add Backup Disk, choose the drive, and follow setup instructions; save the password if you encrypt it
  4. Wait for the first backup to finish, check its date, and test restoring a file to a separate location
Use care during setup: If asked to erase a drive, check that it contains nothing you need before proceeding. Older backups are removed as the backup disk fills.

Add an offsite copy

Pair Time Machine with a cloud backup or a second backup stored elsewhere. A drive beside the Mac can be lost in the same theft or fire. Disconnect a local drive between backup sessions when practical.

iCloud sync does not replace a Time Machine backup of your Mac. Check that cloud-only files and data on other drives are actually included. Time Machine recovery may require reinstalling macOS and then migrating your data; do not assume the backup is a bootable clone.

Back up an Android phone or tablet

Android menus vary by manufacturer and version. Search Settings for Backup if the route below is different on your device.

Check your Google backup

  1. Open Settings → Google → All services → Backup under Backup and restore
  2. Confirm the Google account you can access later and enable backup if needed
  3. Choose Back up now, let it finish, and review Backup details
  4. Check photo and video backup separately in Google Photos; check important downloaded files and app-specific exports too

Google backup can include contacts, messages, settings, and supported app data. Not every app backs up all its data. Restoring to an older Android version can be incomplete.

Make another copy of irreplaceable files

Copy important photos and documents to a computer or external storage, verify that they open, and include those copies in your 3-2-1 plan. A phone plus one cloud copy is only two copies.

Before replacing a phone: Check the last successful backup and access to your account and recovery methods. Keep the original device until you verify the restored data.

Back up an iPhone or iPad

Option 1: iCloud Backup

  1. Open Settings → your name → iCloud → iCloud Backup
  2. Turn on backup for this device and choose Back Up Now
  3. Stay on Wi-Fi until it finishes, then check the last successful backup
  4. Check that your iCloud account has enough storage

Automatic iCloud backups normally run when the device is charging, locked, and connected to Wi-Fi.

Option 2: A computer backup

Connect the device to a Mac and use Finder, or use the Apple Devices app on Windows. Choose the backup option. Enable Encrypt local backup to include sensitive items such as saved passwords and Health data. Keep that password safe; it is needed to use the encrypted backup.

Check separately synced data: Items already synced to iCloud, such as iCloud Photos, are not duplicated in the daily iCloud device backup. Export another copy of irreplaceable photos and files and include it in your computer backup plan.

A computer backup is not offsite when the computer stays beside your phone. Protect the computer backup too, and verify restored data before erasing an old device.

Consumer paid backup services

A paid service can automate an offsite copy. It still needs setup, monitoring, and a restore test. These are examples to compare; the best fit depends on your devices, files, and recovery needs.

Backblaze Computer Backup

Automatic cloud file backup for Windows and Mac, with unlimited data for the licensed computer. Check current billing, file exclusions, external-drive rules, and version-history settings.

Important limit: It excludes operating-system and application files. It is file recovery, not a full-machine system image or an iPhone/Android device backup.

Source: Backblaze: Plans and features

Source: Backblaze: Included and excluded data

IDrive Personal

Cloud backup for multiple computers and selected mobile data under one account, with a storage allowance. Check your plan's capacity, supported data, versioning, and restore tools.

Important limit: Mobile backup covers supported categories, not a complete phone system image. Full-machine backup and recovery requirements vary by platform and feature.

Source: IDrive: Current plans

Source: IDrive: Backup features

iCloud+ and Google One

Paid storage can provide room for the device backups and photos described in the iOS and Android tabs. Confirm what is device backup, photo backup, and sync in your account.

Important limit: Buying more storage does not automatically include every file or produce a full-computer image. Keep a separate copy of irreplaceable data.

Source: Apple: iCloud+ plans

Source: Google One: Storage plans

Before paying, ask these questions

  • Which devices, users, folders, and external drives are covered?
  • What is the renewal price, storage limit, and per-device cost?
  • How long can you recover deleted files and older versions?
  • Can malware or a stolen account delete the backup?
  • How will you restore a large backup, and are there extra charges?
  • Can you recover if the original device, password, or encryption key is lost?
Build a plan, not just a subscription. Use the service as an offsite part of 3-2-1. Keep an independent local backup, protect account access, and confirm that a small test restore works. Prices and features can change; review the linked official plans before purchasing.
