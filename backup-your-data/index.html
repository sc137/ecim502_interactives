Backups give you a way back

Family photos, letters, financial records, and class projects can be hard to replace. A backup is a separate copy you save for later. To restore means to bring files back from that copy after something goes wrong.

How to use this guide: Read at your own pace. Choose a tab above to open a topic. Read to the end to earn its checkmark. Try the Backup Lab and answer the quiz. Complete all eight tabs to claim your certificate. You can return to the device instructions when you need them.

A few words used in this guide

  • Drive: The part of a computer that stores files. An external drive is a separate storage device you connect, usually with a USB cable
  • Cloud: Storage on a company's computers that you reach through the internet
  • Older version: A saved copy from an earlier date, before a file was changed or damaged
  • Operating system: The main software that runs a device, such as Windows or macOS on a Mac

A backup can help after a file is deleted, a drive breaks, a device is lost, or harmful software damages your files.

Hardware failure or loss

A drive can stop working. A phone can be lost. Fire or theft can take both a computer and the drive beside it. Keep another copy offsite—away from your home—so the same event is less likely to take every copy.

Malware and mistakes

Malware is harmful software. One kind, called ransomware, locks files so you cannot open them. Keep a backup that the harmful software cannot reach. Save older copies from before the problem began. Backups also help after accidental deletion.

The 3-2-1 backup rule

3 copies

Your working original plus two backup copies of each important file.

2 kinds of storage

Use two different kinds of storage, such as an external drive and a cloud backup service. This is often called using two “media types.” Two folders on the same drive do not protect you if that drive breaks.

1 copy away from home

Keep at least one copy away from your home, such as a cloud backup or a drive stored safely elsewhere.

Example: Keep the original photos on your computer. Save a backup with older versions on an external drive. Keep another backup in the cloud. When the drive backup finishes, disconnect the drive. Check that both backups include your important files.

Make those copies useful

  • Set backups to run automatically, and check that they finish successfully
  • Keep older versions long enough to discover a problem
  • Keep a backup offline (disconnected) or protected from unwanted changes and deletion
  • Test restoring a few files to a separate folder and open them
  • Use a second sign-in check, such as a code, for your backup account; this is called multifactor authentication
  • Keep backup passwords, recovery codes, and encryption keys safe; these may be needed to unlock a backup
Sync is useful, but check its limits. Sync keeps files the same across devices. If you delete or damage a file, that change may spread to the other copies. Check whether the service lets you recover older or deleted files. Keep a separate backup too.

Backup Lab: What could you get back?

Choose what to save, where to keep the backup, and what goes wrong. Then select Test My Backup Plan to see what you could get back. This is a practice activity. It does not read your files or change your device.

Documents folder

Saves only files in the Documents folder. Photos and files on the Desktop need a separate backup if they are outside Documents. This choice uses less space, but may miss important files.

Home folder

The Home folder is your personal folder on a computer. In this activity, it includes Documents, Pictures, Desktop, and Downloads. It does not include other people's files or the operating system and installed apps.

Full machine

A system image is a backup for rebuilding a computer. In this activity, it saves all users, installed apps, and the operating system. It needs more storage space and the right recovery tools. A service promising “all your files” may not save the operating system.

Platform note: Full machine shows how a Windows system image can work. On a Mac, you normally install macOS first, then bring back your files and apps from Carbon Copy Cloner or Time Machine. See the Mac tab for details.

For this activity: The backup finished yesterday. The problem happens today. All selected files were saved. The disconnected drive and cloud service have an older copy from before the malware attack. You can still sign in to the cloud service. A real backup may leave out some files or run out of space.

Back up a Windows computer

Start with the files you cannot replace. If you also want to bring back Windows, apps, and settings after a drive breaks, consider a system image.

Cloud folders: Windows Backup

  1. Open Start, search for Windows Backup, and open it
  2. Sign in with a personal Microsoft account; work or school accounts do not work in this consumer app
  3. Review the available folders, such as Documents, Desktop, and Pictures, and turn on the ones you need
  4. Run the backup, check that it finished, and check that OneDrive has enough storage space

This keeps selected folders in OneDrive and saves some settings and app information. It is not a full-computer image. You may need to install apps again after replacing the computer.

Add a separate local backup

File History can save older copies of personal files on an external drive. Check which folders it includes. Try bringing back one file to a separate folder, then open it.

Full-disk images: free and paid Windows options

A system image saves Windows, apps, settings, and included files. It can help rebuild your computer after a drive breaks. Choose the tool’s entire-computer option so it also saves the small hidden sections that Windows needs to start. Ask a trusted helper if you are unsure what to select.

These three tools can make a Windows system image. Each requires an external drive or another suitable place to save the backup. The notes below were checked on October 5, 2026.

Veeam Agent for Microsoft Windows Free

Cost: Free

Saves the whole computer and can bring back individual files. Its recovery USB can help restore a backup when Windows will not start.

Main limit: The free version allows one backup job—a set of instructions for what to save and where to save it.

More about the free version

Use an external drive or a supported network location. Direct backups to some cloud storage services require a paid version.

Veeam features · Free-version limits

Hasleo Backup Suite Free

Cost: Free for home use

Saves Windows or an entire drive. You can set backups to run automatically and make a recovery USB for use if Windows will not start.

Main limit: Free for home use. Some features and Windows editions require a paid version.

More about the free version

The free version includes image backup and restore. Copying a system drive directly to another drive, called cloning, requires a paid version. Business use and Windows Education or Enterprise editions also need a suitable paid license. Keeping BitLocker drive encryption after a restore requires a paid edition.

Hasleo features and license details

TeraByte Image for Windows

Cost: US$49.98 for the Drive Image Suite

Saves a drive while Windows is running. It can schedule backups, check backup files for damage, and protect them with a password. Recovery media lets you restore a backup when Windows will not start.

Before buying: A 30-day trial is available. A home-use license covers up to five computers in one household. Check the current price and license terms.

Image for Windows features and trial · Current price and household license

Choosing a tool: Veeam and Hasleo offer free home backup options. Image for Windows is a paid option. Try a tool with a trusted helper if needed. Check that you can find your backup and use its recovery instructions before relying on it.

Check that you can get your files back

  1. Save an image on a separate drive. If the tool offers a check for backup damage, called verification, run it
  2. Create a recovery USB using the backup tool. This can start the computer when Windows cannot. Check that it starts and can find your backup. Get help with this check if needed, and exit without restoring anything
  3. Restore a few sample files to a separate folder and open them
  4. For a full-computer test, restore the image to a spare drive or test computer, with an experienced helper if needed. Check that Windows starts and your files open

A full-computer restore replaces what is on the selected drive. Check the destination carefully. Keep your working drive safe during a test. Save backup passwords and BitLocker recovery keys somewhere you can reach without this computer. BitLocker keys unlock an encrypted drive.

Opening a restored file is a useful first check. A full-computer test also checks whether Windows can start after recovery.

Recovery procedure: Veeam: Whole-computer recovery using rescue media

Older advice may be out of date. Microsoft no longer develops the older Backup and Restore (Windows 7) system-image feature. Macrium Reflect Free no longer receives updates. Choose a tool that is still updated and works with your Windows version.

Check the gaps: Check files outside your chosen folders, other people’s accounts, and other drives. Files stored only in the cloud may need another backup. Disconnect your backup drive when it is not in use. Keep a copy away from home too.

Back up a Mac

Use Time Machine

Time Machine is Apple's built-in backup tool for personal data, including documents, photos, and apps. It keeps earlier versions so you can recover an older file.

  1. Connect an external drive with enough space for your backup
  2. On macOS Ventura or later, open System Settings → General → Time Machine
  3. Select Add Backup Disk, choose the drive, and follow the setup instructions. If you protect the backup with encryption, keep its password safe
  4. Wait for the first backup to finish, check its date, and test restoring a file to a separate location
Use care during setup: If asked to erase a drive, check that it contains nothing you need before proceeding. Older backups are removed as the backup disk fills.

Carbon Copy Cloner and whole-Mac recovery

Carbon Copy Cloner (CCC) is a paid tool that can save backups to an attached drive on a schedule. It can keep older copies of your files. These saved copies are called snapshots. A standard CCC backup saves your files, the apps you installed, and your settings. It does not save the macOS operating system itself.

To recover after a drive breaks or a Mac is replaced:

  1. Install macOS, or use the macOS already installed on the replacement Mac
  2. Connect the drive containing your complete CCC backup
  3. Use Migration Assistant, Apple's tool for moving files, apps, and accounts, to bring your information back

Include all the accounts and files you need in the backup. Time Machine is a free alternative that also lets you bring your information back after macOS is installed. Either option needs backup storage.

A Mac recovery backup differs from a Windows disk image. Some CCC backups can start a Mac directly from an external drive. This is called a bootable backup. Bombich, the maker of CCC, advises against relying on this method. A standard CCC backup can bring back your information after macOS is installed.

Sources: Bombich: What a standard CCC backup includes; Bombich: Whole-Mac recovery and Migration Assistant; Bombich: Current CCC pricing

What about a Mac disk-image file?

CCC can put a backup inside one large disk-image file. Bombich advises saving your regular Mac backup directly to an attached drive instead. Disk-image files can be harder to recover and may be damaged if a connection is lost, especially over a network.

Source: Bombich: Disk-image support and limitations

Check your Mac recovery plan

  • Check when the last backup finished, which drives and folders it includes, and whether it keeps older copies
  • Restore a few files to another folder and open them
  • Check that you have the backup drive and its password. Ask a trusted helper to show you macOS Recovery, Apple's built-in repair and reinstall tools
  • If a spare Mac is available, ask a trusted helper to test bringing back your information with Migration Assistant. Opening one restored file does not check the whole recovery process

Add an offsite copy

Pair Time Machine with a cloud backup or a second backup stored elsewhere. A drive beside the Mac can be lost in the same theft or fire. Disconnect a local drive between backup sessions when practical.

iCloud sync does not replace a Time Machine backup of your Mac. Check that files stored only in the cloud and files on other drives are included in your backup. To recover a whole Mac, you may need to install macOS first, then bring back your information.

Back up an Android phone or tablet

Android menus vary by manufacturer and version. Search Settings for Backup if the route below is different on your device.

Check your Google backup

  1. Open Settings → Google → All services → Backup under Backup and restore
  2. Confirm the Google account you can access later and enable backup if needed
  3. Choose Back up now, let it finish, and review Backup details
  4. Check photo and video backup separately in Google Photos
  5. Check important downloaded files too. Some apps need you to save a separate copy using their own backup or export option

Google backup can include contacts, messages, settings, and supported app data. Not every app backs up all its data. Restoring to an older Android version can be incomplete.

Make another copy of irreplaceable files

Copy important photos and documents to a computer or external storage, check that they open, and include those copies in your 3-2-1 plan. A phone plus one cloud copy is only two copies.

Before replacing a phone: Check when the last backup finished. Make sure you can sign in to your account, even without this phone. Keep the original device until you check that your files and other information came back.

Back up an iPhone or iPad

Option 1: iCloud Backup

  1. Open Settings → your name → iCloud → iCloud Backup
  2. Turn on backup for this device and choose Back Up Now
  3. Stay on Wi-Fi until it finishes, then check the last successful backup
  4. Check that your iCloud account has enough storage

Automatic iCloud backups normally run when the device is charging, locked, and connected to Wi-Fi.

Option 2: A computer backup

  1. Connect the iPhone or iPad to your computer
  2. On a Mac, open Finder. On Windows, open the Apple Devices app. Select your device
  3. Choose the option to back up to this computer
  4. Choose Encrypt local backup to protect it with a password. This also lets the backup include saved passwords and Health data
  5. Save the backup password somewhere safe, and start the backup. You need this password to use the backup later
Check your photos separately: If iCloud Photos is turned on, those photos are stored through that service. They are not also saved in your daily iCloud device backup. Download another copy of photos you cannot replace, and include it in your computer backup plan.

A computer backup is not offsite when the computer stays beside your phone. Protect the computer backup too, and check that your information came back before erasing an old device.

Paid backup and storage services

A paid cloud service can save a copy away from home automatically. You still need to set it up, check that backups finish, and try bringing back a file. Compare these examples based on the devices and files you want to protect.

Backblaze Computer Backup

Automatically saves Windows or Mac files to the cloud. It offers unlimited backup storage for the computer covered by your plan. Check the price, which files and external drives it includes, and how long it keeps older copies.

Important limit: It does not back up the operating system or installed apps. It can bring back your files, but cannot rebuild the whole computer from a system image. It is not a full backup of a phone or tablet.

Source: Backblaze: Plans and features

Source: Backblaze: Included and excluded data

Arq Backup

Works on both Windows and Mac. It can automatically save your chosen files to a cloud service or an attached drive. It keeps older copies so you can bring back a file from before it was changed or damaged.

Setup and cost: With the Arq Backup app, you choose where to store the backup. Cloud storage is not included and may cost extra. Arq Premium includes cloud storage. Keep your backup encryption password safe; it protects your saved files.

Source: Arq Backup: Windows and Mac features

IDrive Personal

Can save files from several computers and some phone or tablet information under one account. Each plan has a storage limit. Check what it saves, how long it keeps older copies, and how to bring your files back.

Important limit: Phone and tablet backup saves only the types of information the app supports. It does not copy everything on the device. Check the separate requirements for full-computer backup on your device.

Source: IDrive: Current plans

Source: IDrive: Backup features

iCloud+ and Google One

These plans give you more storage for backups and photos. See the iPhone & iPad and Android tabs for setup. Check which information is saved in a device backup and which is kept through sync.

Important limit: Buying more storage does not automatically include every file or produce a full-computer image. Keep a separate copy of irreplaceable data.

Source: Apple: iCloud+ plans

Source: Google One: Storage plans

Before paying, ask these questions

  • Which devices, users, folders, and external drives are covered?
  • What will it cost when the plan renews, how much can I store, and do I pay for each device?
  • How long can you recover deleted files and older versions?
  • Can malware or a stolen account delete the backup?
  • How will you restore a large backup, and are there extra charges?
  • Can you reach your backup if the original device is lost? What passwords or keys will you need?
A subscription is one part of your plan. Use the service for a copy away from home. Keep a separate backup on a drive too. Protect your account and try bringing back a file. Prices and features can change. Check the linked plans before buying.
