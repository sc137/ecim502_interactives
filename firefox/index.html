Browser Basics: The Program That Opens the Web

The main idea

A web browser is an application that retrieves, interprets, and displays websites. Firefox, Chrome, Safari, and Edge are browsers.

Retrieves information

When you enter a web address or select a link, the browser requests files from a web server.

Builds the page

The browser interprets HTML for structure, CSS for appearance, and JavaScript for behavior.

Helps you navigate

Tabs, bookmarks, history, downloads, passwords, privacy settings, and accessibility tools help you use the web.

Browser or search engine?

Two tools that work together but do different jobs
Tool What it does Examples
Web browser Opens, displays, and lets you interact with websites. Firefox, Chrome, Safari, Edge
Search engine Finds web pages that may answer a question. Google, Bing, DuckDuckGo

A simple way to remember

The browser is the vehicle. A search engine is one destination you can visit with it. You can use several search engines inside the same browser.

Browser History: From One Browser to Many

Select a year or period to explore a milestone. The timeline distinguishes when the first browser was written from when web software became more widely available.

1990

WorldWideWeb, the first browser-editor

Tim Berners-Lee wrote the first web browser and editor at CERN on a NeXT computer. It was later renamed Nexus to avoid confusion with the World Wide Web itself.

Why it matters: The earliest browser could both view and edit web documents.

Browser Families: What Works Behind the Window

A browser uses more than one engine

A rendering engine turns page code into the layout you see. A JavaScript engine runs JavaScript instructions. The names are related, but they are not interchangeable.

Common browser families and their engines
Browser family Common examples Rendering engine JavaScript engine
Chromium on desktop and Android Chrome, Edge, Brave, Opera, Vivaldi Blink V8
Safari Safari and Apple web technology WebKit JavaScriptCore
Firefox desktop and Android Firefox Gecko SpiderMonkey
Firefox on iPhone and iPad Firefox interface on iOS/iPadOS WKWebKit JavaScriptCore
Important platform exception

Firefox uses Gecko on desktop and Android. On iPhone and iPad, Firefox uses Apple’s WKWebKit to display web content. The Firefox interface and account features remain Mozilla products.

Why Firefox matters

Most major desktop browsers use Chromium and Blink. Firefox maintains a separate general-purpose engine, Gecko. Multiple independently developed engines help web standards get tested across more than one implementation.

Install Firefox: Choose Your Device

Select the device you will use for the assignment. The instructions below come from Mozilla’s current support guidance.

Choose a device to display its instructions.

Install Firefox on Windows

  1. Open the official Firefox download page.
  2. Select Get Firefox or Download Firefox.
  3. Open the downloaded installer. If Windows asks whether the installer may make changes, confirm only after checking that the publisher and source are Mozilla.
  4. Wait for installation to finish, then open Firefox.

Other official option: Windows 10 or 11 users may install Mozilla Firefox from the Microsoft Store. Windows in S mode can block installers that do not come from the Store.

Mozilla’s Windows installation help

Install Firefox on Mac

  1. Open the official Firefox download page.
  2. Download Firefox and open Firefox.dmg.
  3. Drag the Firefox icon into the Applications folder.
  4. Eject the Firefox disk image, then open Firefox from Applications. Select Open if macOS displays its first-launch confirmation.

Do not run Firefox permanently from the downloaded disk image. Move it to Applications first.

Mozilla’s Mac installation help

Install Firefox on iPhone or iPad

  1. Open the Apple App Store.
  2. Search for Firefox.
  3. Confirm that the developer is Mozilla. Product subtitles can change.
  4. Select Get, complete the App Store confirmation, and open Firefox.

Current Mozilla guidance requires iOS 15 or later. Firefox on iPhone and iPad uses WKWebKit rather than Gecko.

Mozilla’s mobile installation help

Install Firefox on Android

  1. Open Google Play or another official marketplace supported by Mozilla.
  2. Search for Firefox.
  3. Confirm that the developer is Mozilla.
  4. Select Install, then open Firefox.

Current Mozilla guidance requires Android 8.0 or later. If Firefox does not appear in Google Play, the device may not be compatible.

Mozilla’s mobile installation help

Install Firefox on a Chromebook

This is an advanced installation

Mozilla’s current desktop Firefox method for ChromeOS is not the same as the ordinary Android installation.

  1. Confirm that the Chromebook uses an x86 processor and ChromeOS 80 or later.
  2. Enable Linux support in ChromeOS settings.
  3. Follow Mozilla’s current instructions to install the recommended DEB package or use Flatpak.

Because these steps use Linux commands and system settings, ask for assistance if you are not comfortable making those changes.
